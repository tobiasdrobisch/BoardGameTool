# Boardgame Tool 🎲

A web-based tool to create, manage, and score board game matches  
(currently supporting **Kingdom Builder**).

With this tool you can:
- Select players
- Create matches
- Automatically generate tasks
- Enter scores with live total calculation
- Store and evaluate match results

---

## 📦 Tech Stack

### Backend
- Python 3.10+
- FastAPI
- SQLAlchemy
- PostgreSQL (recommended) or SQLite
- JWT Authentication

### Frontend
- Plain HTML / CSS / JavaScript
- No external JS frameworks
- REST API communication via Fetch
